Core User Loop Architecture

How data travels across components without cognitive debt or external dependencies:

3. Cognitive Debt Meter Heuristic weighted analyzer flags complexity risks and bloat in real-time.
4. Live Wireframe Mock Instant UI preview generated to validate the single-loop PoC before code.
5. Artifact Exporter Generates compliant scope.md, prd.md, and spec.md files.
